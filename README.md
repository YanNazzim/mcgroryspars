# Mcgrory SPARs

This React application is built with Vite.

## Available Scripts

### `npm start`

Runs the development server at [http://localhost:5173](http://localhost:5173).

### `npm run dev`

Runs the Vite development server.

### `npm test`

Runs the Vitest test suite once.

### `npm run build`

Creates an optimized production build in the `dist` directory.
